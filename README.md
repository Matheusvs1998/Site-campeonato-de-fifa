# Campeonato EA FC 26

Site estático para um campeonato de EA FC 26.

## Arquivos incluídos
- `index.html` — página principal do campeonato
- `styles.css` — estilos responsivos
- `script.js` — menu móvel e feedback do formulário

## Como usar
1. Abra `index.html` no navegador.
2. Edite o conteúdo e as datas do campeonato conforme necessário.


## Tecnologias
- React (via CDN)
- Supabase (Banco de dados e persistência)
- CSS3 com variáveis modernas

## Moderação do site
Moderação controlada pelo supabase mediante ao ip do admin.
